# ModForge AI

**A free Minecraft Java mod workshop** by Prosto.

ModForge AI helps create and troubleshoot mods for Fabric, NeoForge, and Forge. Its workflows cover complete project scaffolding, pixel-art textures, mobs and AI, model previews, compatibility checks, error repair, and build orchestration through an available execution host or connected GitHub Actions.

## Features

- Create complete Minecraft Java mod project structures.
- Generate block, item, armor, and other pixel-art PNG textures.
- Build entities with attributes, AI, spawning, loot, and sounds.
- Inspect model JSON and prepare preview artifacts.
- Diagnose loader, dependency, resource, and API conflicts.
- Repair Gradle, compiler, and runtime errors.
- Use an available execution host or connected GitHub Actions to build and verify a real JAR.

## Build status matters

A generated project is not necessarily a successfully compiled or game-tested mod. ModForge AI distinguishes generated source from a successful build and must not claim a JAR exists until the actual artifact has been verified. Build execution depends on an available execution host or connected GitHub Actions account.
